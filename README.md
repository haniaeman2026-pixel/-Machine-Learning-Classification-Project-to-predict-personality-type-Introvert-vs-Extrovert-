# -Machine-Learning-Classification-Project-to-predict-personality-type-Introvert-vs-Extrovert-
 Personality Prediction System using Machine Learning
 Overview

This Machine Learning project focuses on predicting whether a person is an Introvert or Extrovert using behavioral and social interaction data. The project applies multiple classification algorithms to analyze personality patterns and compare model performance.

 Tech Stack

Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn

 Models Implemented
Logistic Regression
Decision Tree Classifier
Random Forest Classifier

🏆 Best Performing Model: Logistic Regression with 90.4% Accuracy

 Project Workflow

Data Preprocessing • Exploratory Data Analysis (EDA) • Feature Scaling • Model Training • Model Evaluation

Conclusion

This project provided practical experience in Machine Learning classification, data visualization, and predictive analytics. It also strengthened my understanding of model evaluation and real-world ML workflows through hands-on implementation.
